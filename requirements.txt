# Pinned deliberately, not with >= ranges.
#
# This app is deployed on Streamlit Community Cloud, which rebuilds the
# environment on every container restart. With open ranges that meant each
# rebuild pulled whatever was newest: the app was silently moved onto
# Python 3.14 with new majors of pandas, numpy and transformers, months after
# the last commit. An app that works in March should still work in September.
#
# Deployment target: Python 3.14, linux x86_64.
# Every version below was resolved against that target and confirmed to have a
# matching wheel, so the build cannot fall back to a source compile.
#
# To refresh deliberately:
#   pip install --dry-run --python-version 3.14 --only-binary=:all: \
#     --platform manylinux_2_28_x86_64 --target /tmp/r --report r.json -r requirements.txt
